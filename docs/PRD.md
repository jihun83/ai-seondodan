## 2. 목표와 대상

**목표**
- 처음 보는 사람도 설명 없이 30초 안에 규칙을 알고 놀 수 있다.
- 90초 한 판으로 끝나서, 연수 중 짧게 돌려 보기 좋다.
- 코드가 파일 하나라, 연수생이 직접 열어 보고 고쳐 볼 수 있다.

**대상**
- 연수에 참여한 교사, 그리고 그 교사가 수업에서 보여 줄 학생
- PC 브라우저와 휴대폰 브라우저 모두

## 3. 게임 규칙

### 3.1 판
- 8×8 칸, 보석 7종류.
- 새 판은 **처음부터 사라질 줄이나 사각형이 없고**, **둘 수 있는 수가 하나 이상** 있게 만든다.

### 3.2 바꾸기
- 위·아래·왼쪽·오른쪽으로 **이웃한 두 보석**만 바꿀 수 있다.
- 바꿔서 사라질 묶음이 생기지 않으면 **원래 자리로 되돌린다**(점수 변화 없음).

### 3.3 사라지는 조건
| 조건 | 설명 |
| --- | --- |
| 가로 줄 | 같은 보석 3개 이상이 가로로 이어짐 |
| 세로 줄 | 같은 보석 3개 이상이 세로로 이어짐 |
| 2×2 사각형 | 같은 보석 4개가 2×2로 모임 (v1.1에서 추가) |

여러 조건이 동시에 생기면 해당 보석을 모두 한꺼번에 없앤다.

### 3.4 떨어짐과 연쇄
- 빈 칸 위의 보석이 아래로 떨어지고, 맨 위에서 새 보석이 내려와 채운다.
- 채운 뒤 다시 사라질 묶음이 생기면 계속 없앤다. 이것이 **연쇄(콤보)**다.

### 3.5 둘 곳이 없을 때
- 연쇄가 끝난 뒤 둘 수 있는 수가 없으면 "섞는 중…"을 띄우고 판을 새로 만든다(3.1 조건을 지키는 새 배치).

### 3.6 시간과 끝
- 한 판은 **90초**. 남은 시간 막대가 줄어들고, 10초 이하면 막대가 빨갛게 바뀐다.
- 시간이 다 되면 입력을 막고, **진행 중인 연쇄가 끝난 뒤** 점수를 확정해 "시간 종료!" 화면을 띄운다.

## 4. 점수

한 번에 사라지는 보석마다:

```
얻는 점수 = 사라진 보석 수 × 10 × 콤보 단계 × 크기 보너스
```

| 요소 | 값 |
| --- | --- |
| 콤보 단계 | 바꾼 직후 첫 제거 1, 연쇄될 때마다 +1 |
| 크기 보너스 | 한 번에 사라진 보석 수가 3개면 ×1, 4개면 ×1.5, 5개 이상이면 ×2 |
| 힌트 사용 | −50점 (점수는 0 아래로 내려가지 않음) |

**예시**
- 3개 한 줄: 3 × 10 × 1 × 1 = 30점
- 2×2 사각형: 4 × 10 × 1 × 1.5 = 60점
- 연쇄 2단계에서 3개: 3 × 10 × 2 × 1 = 60점

**화면 알림**: 연쇄 2단계부터 "콤보 x2!", 첫 제거가 사각형이면 "사각형!", 5개 이상이면 "대단해요!"

## 5. 조작

| 방법 | 동작 |
| --- | --- |
| 끌기 | 보석을 누른 채 이웃 방향으로 칸의 약 1/3 이상 밀면 바꾼다 (마우스·터치 공통) |
| 두 번 누르기 | 하나를 누르면 선택(흔들림 표시) → 이웃 보석을 누르면 바꾼다. 이웃이 아니면 선택만 옮기고, 같은 보석을 다시 누르면 선택 해제 |
| 💡 힌트 | 둘 수 있는 한 쌍을 약 2초간 반짝인다. 50점 차감 |
| 🔄 새 게임 | 언제든 판·점수·시간을 처음으로 |
| 다시 하기 | 시간 종료 화면에서 새 게임 |

애니메이션 중에는 입력을 받지 않는다.

## 11. 남은 과제와 주의

- **공개 범위**: 연수용 예외로 저장소를 공개했다. 코드와 commit 작성자 정보가 누구에게나 보인다. 연수가 끝나면 비공개로 돌릴지 정한다(비공개로 돌리면 게임 주소도 닫힘).
- **commit 연결**: 기존 commit 4개의 작성자 이메일은 다른 GitHub 계정에 붙어 있어 `jihun83`으로 표시되지 않는다. 이후 commit은 `jihun83` 계정에 등록된 이메일로 기록된다.
- **사람 시험**: 휴대폰 터치 조작 시험이 남아 있다.
- **두 판 함께 관리**: v1.1과 v2.0은 코드가 따로라, 규칙을 바꾸면 두 곳을 모두 고쳐야 한다. 연수가 끝나면 한쪽만 남길지 정한다.
- **빌드 결과물 commit**: 지금 Pages 설정(브랜치에서 바로 배포)을 바꾸지 않으려고 빌드 결과를 저장소에 넣었다. 표준 방식은 GitHub Actions 자동 배포이며, 바꾸려면 Pages 설정 변경과 함께 따로 진행한다.
